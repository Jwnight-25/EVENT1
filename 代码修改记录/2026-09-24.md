# 2026-09-24｜基础项目底座

对应提交：`c6db488`（已同步至 GitHub `main`）

## 完成功能

- 建立 FastAPI 版本化接口、PostgreSQL 数据持久化、SQLAlchemy 数据模型和 Alembic 数据库迁移。
- 增加时间序列 CSV 导入：支持 UTF-8 与 GB18030；可指定时间列、数值列、名称、单位、频率、来源和时区；记录原始值并跳过重复时间点。
- 增加数据集列表、摘要、观测值和图表序列接口，并在前端提供“数据整理”页面，支持选文件、映射列、导入和查看折线图。
- 增加“最后观测值延续”基线预测：按时间顺序进行滚动验证，保存 MAE、RMSE、MAPE 和经验误差区间；前端可选择数据集和周期查看历史与预测曲线。
- 增加云端 GPT 预测结果解释接口，可选联网搜索；解释只读取服务端保存的预测记录，AI 不生成量化预测值。
- 关键 API 密钥通过本机环境配置读取，不进入前端或 Git。
- 补充本机启动说明、API 契约和需求决策记录；移除页面加载外部字体的网络依赖。
- 在项目首页增加逐次修改记录入口，便于后续查阅。

## 主要优化与边界

- 对样本不足、预测周期短于数据采样间隔等情况返回明确提示，不生成演示数据。
- API 健康状态与业务数据是否已接入分开处理。
- 当前不使用 Docker、用户登录、推送或 WebSocket。
- 自动免费数据源尚未接入；当前通过 CSV 导入数据。
- 首版预测只是朴素基线，交易日历、节假日及非规则时间序列仍需按具体数据源完善。
- 本次未做连接实际 PostgreSQL 的完整运行验证。
