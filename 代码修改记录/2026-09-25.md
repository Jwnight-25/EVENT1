# 2026-09-25 多品种选择与碳酸锂样本接入准备

## 完成的功能与优化

- 前端增加 BU 石油沥青、LC 碳酸锂品种选择；侧栏和顶部入口保持同步。
- 数据整理与预测中心按所选品种筛选数据集；导入 CSV 时自动记录当前品种。切换品种时清除旧图表并选择新品种数据，避免误显示其他品种的数据。
- 后端数据集查询支持 `instrument` 筛选；总览、行情、基本面、合约、资讯和模型预留接口接收当前品种代码。
- 平台标题和启动说明改为多品种；本地 PostgreSQL 示例配置切换为 `futures_research` 数据库。
- 增加碳酸锂样本口径、日期覆盖、时效限制和本地导入步骤说明。提取的 CSV 保存在忽略提交的 `data/raw/`，不纳入 GitHub 上传。
- AI provider 维持 GPT-6 Luna Responses API 与可选网页搜索配置；API key 仅由用户保存在本机 `.env`。
- 用户启动 PostgreSQL 17 后，创建本机 `futures_research` 数据库、安装后端依赖、执行 Alembic 迁移，并实际导入 1,407 条 LC 样本数据。
- 用户配置的 OpenAI key 已通过 API 身份认证；GPT-6 Luna Responses API 请求收到 `credit_balance_exhausted`（账户没有可用 API 额度），充值/设置 API 账单后才能完成模型调用。
- 修正 PostgreSQL 驱动在批量导入时行数可能返回负值的问题，改为按数据库返回的新增记录 ID 统计导入数。
