# 本地样本数据

## 碳酸锂

原始文件由项目使用者提供：`【ITF-新能源】碳酸锂数据库2026.xlsx`。本地整理文件：`raw/lithium_carbonate_battery_grade_spot_sample.csv`。

- 品种代码：LC
- 序列：电池级碳酸锂现货平均价
- 口径：日频，日期与数值两列，数值单位为元/吨
- 有效样本：1,407 条；日期范围 2020-01-02 至 2026-01-19
- 数据质量：整理结果中未发现空值或重复日期
- 时效说明：原工作簿生成于 2026-01-21，样本不是实时行情；导入后可用于验证导入、图表及基线预测链路，不代表 LC 期货合约报价

原工作簿和提取后的 CSV 均不提交到 GitHub。CSV 受 `.gitignore` 的 `data/raw/**` 规则保护。需要使用时，在本地启动前端，选择品种“碳酸锂 · LC”，进入“数据整理”，选择 `data/raw/lithium_carbonate_battery_grade_spot_sample.csv`；时间列选 `date`、数值列选 `value`，单位填 `元/吨`，频率填 `日`，来源说明填“用户提供的碳酸锂数据库样本”。数据库连接完成后即可导入并在预测中心选择该序列。
