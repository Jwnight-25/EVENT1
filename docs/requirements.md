# 需求基线

需求记录整理自用户提供的两份 V1.0 文档。原始文档是具体要求的最终来源。

## 项目范围

- 第一阶段仅聚焦上海期货交易所石油沥青 BU，架构预留其他期货品种扩展能力。
- 核心观察当前主力合约及之后最近两个合约；保留单合约原始数据，连续序列单独生成并记录规则。
- 预测周期：5分钟、30分钟、1天、1个月、3个月。
- 短期结果每2分钟更新，长期结果每日更新；实际频率受数据源能力约束。

## 页面

- P0：市场总览、行情分析、预测中心、基本面 Profile。
- P1：新闻与事件页面；总览可展示新闻摘要。
- AI预测下钻页：模型详情，展示训练/验证信息、拟合、Loss、残差、时域/频域、特征重要性和评估。

## 数据与模型

- 行情：OHLC/Last、成交量、持仓量及可获得的成交额；多合约与期限结构。
- 基本面：库存（不同口径分开）、产量、开工率、进出口、需求代理、原油及季节性。
- 数据保留来源、采集/发布时间、更新时间、单位、频率和原始值；原始层与处理层分离。
- 模型需与简单基线比较，使用时间有序验证（如 Walk-forward、Rolling/Expanding Window）和独立测试区间。
- 缺数或信号弱时明确显示不确定性；不得伪造市场数据、模型概率或性能。

## 前端需求

- 专业金融研究终端风格，桌面优先、响应式、多图表、显示数据更新时间。
- 基本面页面包含主力信息、库存图表、区域概览与近期资讯。
- 行情分析覆盖分时、K线/日线、成交量、持仓、常用指标及多合约比较。
- 预测页面展示方向、价格、区间、置信信息、模型、更新时刻、历史表现和主要驱动因素。

## 待数据调查确认

- 免费/官方数据源能否稳定提供 BU 分时、5分钟、日线及各合约历史行情。
- 库存、仓单、产量、开工、贸易、需求与原油数据的定义、更新频率、发布时间、历史深度、授权和缺失情况。
- 现货价格/基差的可用来源与统一口径；各数据源分别能支持哪些预测周期。
- 数据库及最终生产技术选型。
